## What is App Store URL Cleaner
[App Store URL Cleaner](https://github.com/featured508/appstore-url-cleaner/) is a simple Python script that removes unnecessary path elements from **App Store URLs**.

## Example of use
**Input:** `https://apps.apple.com/us/app/apple-developer/id640199958`<br>
**Output:** `https://apps.apple.com/app/id640199958`
